# 数字孪生 UAV-LEO 边缘计算 —— 初步结果汇总（2026-08-28）

> 探索版：机制量化 + 自适应同步。所有数字为修复版 env + 40 集（seed 73+episode）/ k3 为 5 seeds × 10 集。
> 配置：hard（12 用户/30 时隙）、stress（16 用户）、k3（3 UAV/51 用户/3 热点/2 km）。

**结论**：同步周期是性能第一敏感因素。每失同步一个时隙，单 UAV hard 损失 30~70 reward；
τ=10 时性能为完美同步的 1/3（-80.7 → -269.9）。stress 与 k3 更陡（任务负载更重）。
τ=1 数值与无孪生基准一致（-80.7 vs 论文 PMEO -81.65，误差来自 seed 偏移），校准通过。

## RQ2 预测模型与误差鲁棒性（hard，τ=3，40 集）

| predictor | reward | 说明 |
|---|---|---|
| freeze（位置+任务全冻结） | -179.1 | 最保守 |
| linear（位置线性外推，任务冻结） | -178.5 | 位置外推收益小（用户匀速） |
| resample（热点感知任务重采样） | -186.5 | **盲目重采样比冻结更差**：孪生与物理随机序列不匹配 |
| linear_noise 5%/10%/20% | -178.7/-178.6/-178.9 | 位置噪声 20% 内几乎无影响 |

**结论**：性能崩塌的主因不是位置误差，而是**任务状态漂移**（task_bits 每时隙全量重采样，
冻结即错位；盲目重采样更错位）。位置外推与位置噪声鲁棒。→ 孪生质量的关键在"任务/负载动态建模"，
而非位置预测。这也解释了 RQ4 自适应同步的触发逻辑必须包含任务漂移。

## RQ3 决策器鲁棒性（hard，`rq1_single.csv` 提取）

| 方法 | τ=1 | τ=3 | τ=10 | agree(τ=1) | agree(τ=10) |
|---|---|---|---|---|---|
| PMEO (post-move) | -80.7 | -178.5 | -269.9 | ~0.95 | ~0.55（见 CSV） |
| current-exact | -83.1 | -179.9 | -274.9 | ~0.95 | ~0.55 |
| MPC-H3 | -80.2 | -176.8 | -253.3 | ~0.95 | ~0.55 |

**结论**：三个决策器在孪生误差下**趋同**（τ=10 时差 <20 reward）；决策顺序优势（post-move vs
current 的 +2.5）被孪生误差淹没一个数量级。**发现：孪生状态质量是决策顺序机制生效的前提**——
没有新鲜的孪生状态，卸载层的最优性无从谈起。这正好把"数字孪生"与现有"决策顺序"故事串联成
一条因果链：孪生新鲜度 → 位置/负载精度 → 决策顺序收益。

## RQ4 误差触发自适应同步（hard，40 集）

| 机制 | 平均同步次数 | reward |
|---|---|---|
| fixed τ=1 | 30.0 | -80.7 |
| fixed τ=2 | 15.0 | -152.4 |
| fixed τ=3 | 10.0 | -178.5 |
| fixed τ=5 | 6.0 | -209.9 |
| fixed τ=10 | 3.0 | -269.9 |
| adaptive δ=5m（probe 位置+任务漂移） | 12.4 | -163.9 |
| adaptive δ=10m | 12.3 | -164.5 |
| adaptive δ=20m | 11.8 | -166.2 |

k3（5 seeds × 10 集，`rq4_k3.csv`）：adaptive δ=5 用 48 次同步达到 -5517，
与 fixed τ=2（51 次同步，-5460）持平（差 1.0%）；δ 5~20m 不敏感。

**结论**：误差触发同步**无需先验 τ** 即可自动逼近固定周期最优（12.4 次 ≈ fixed τ=2~3 之间，
reward -163.9 vs 插值 ≈ -165）。δ 在 5~20m 内不敏感（触发主要由任务漂移主导）。
诚实边界：本环境任务每时隙全量重采样，任务漂移"永远存在"，自适应省同步的空间小；
在任务到达有时间相关性的真实系统（突发/稀疏）中，事件触发同步的收益预计显著更大。
工程结论：**该环境下同步周期应 ≤2 时隙**，或直接采用自适应（免先验调参）。

## RQ4b 突发流量变体（burst）：自适应从"持平"变"硬优势"

> 配置：`burst_cycle=15, burst_on=3, burst_offset=4, burst_arrival_mult=4,
> burst_size_mult=2`——每 30 时隙有 6 个突发时隙（4-6、19-21），突发时活动任务数
> 2-4 → 9-11 且尺寸 ×2。数据：`rq1_*_burst.csv` / `rq4_*_burst.csv`；
> 图：`fig_burst_{single,k3}.png`、`fig_sync_timing_burst.png`。

### RQ1 burst：绝对陈旧代价更大

单 UAV（40 集）：τ=1 → -207.0（完成率 1.00），τ=10 → -437.8（0.68）；
k3（5 seeds×10 集）：τ=1 → -6307，τ=10 → -11360。与 i.i.d. 相比，突发场景的
**绝对**陈旧代价更高（单 UAV τ=1→10 损失 231 vs i.i.d. 189；k3 5053 vs 3997），
因为突发时隙负载 4-8 倍放大，错过一个突发时隙的代价远高于错过一个平静时隙。

### RQ4 burst：负载感知触发支配固定周期前沿

单 UAV（40 集）：

| 机制 | 同步次数 | reward | 完成率 |
|---|---|---|---|

| fixed τ=3 | 11.0 | -348.9 | 0.77 |
| fixed τ=5 | 7.0 | -366.8 | 0.77 |

| adaptive load δ=80m | 6.4 | -396.9 | 0.70 |
| adaptive per_user δ=10m | 23.8 | -226.2 | 0.97 |

k3（5 seeds×10 集）：

| 机制 | 同步次数 | reward | 完成率 |
|---|---|---|---|
| fixed τ=1 | 101.0 | -6307.2 | 1.00 |
| fixed τ=2 | 51.0 | -8339.2 | 0.90 |
| fixed τ=3 | 34.0 | -9738.3 | 0.83 |
| fixed τ=5 | 21.0 | -10118.4 | 0.87 |
| fixed τ=10 | 11.0 | -11360.4 | 0.79 |
| adaptive load δ=25m | 49.4 | **-8162.9** | 0.90 |
| adaptive load δ=30m | 42.9 | **-8402.4** | 0.88 |
| adaptive load δ=40m | 32.3 | **-8794.2** | 0.88 |
| adaptive load δ=50m | 26.1 | **-9047.5** | 0.86 |
| adaptive per_user δ=10m | 94.0 | -6479.6 | 1.00 |

**结论**：i.i.d. 场景自适应只能"持平"最优固定周期；**burst 场景下负载感知触发
（`task_mode="load"`，触发指标 = 孪生 vs 物理的聚合负载相对变化）在
reward-同步次数平面上支配固定周期前沿**：
- k3：δ=40（32.3 次同步）比 fixed τ=3（34 次）好 **9.7%**；δ=50（26.1 次）比
  fixed τ=5（21 次）好 **10.6%**；δ=25（49.4 次）与 fixed τ=2（51 次）相当且略优。
- 单 UAV：δ=40（14.6 次）以更少同步次数超过 fixed τ=2（16 次）；δ=50/60 显著超过
  fixed τ=3（+9.0%/+3.9%）。δ=80 过松（触发太少），为诚实边界。
- 对照：per_user 触发在 burst 下"过火"（k3 用 94 次同步才逼近 τ=1）——逐用户原始
  差异对 i.i.d. 重采样噪声过敏感；负载感知指标只对"负载跃迁"（突发开始/结束）响应。
- 同步时机诊断（`fig_sync_timing_burst.png`）：load 触发同步集中在突发边界
  （4-7、19-22），平静期仍有少量误触发（窗口内仍是 i.i.d. 重采样，分布内噪声无法
  完全区分），但比 per_user 干净得多。

**与 i.i.d. 的对照结论**：RQ4-hard 的"诚实边界"预测被验证——任务到达有时间相关性
（突发）时，事件触发同步收益显著；触发指标的选择取决于流量动态：
i.i.d. → 逐用户漂移；突发 → 聚合负载跃迁。自适应免去先验 τ/流量类型调参，
在 burst 下同时取得更好 reward 与更少同步。

**诚实边界**：(1) burst 变体仍是"窗口内 i.i.d. 采样"（概率×4 + 尺寸×2），
不是 MMPP/真实相关到达模型；(2) δ 仍需选择（单 UAV 40-60m / k3 25-50m 最优，
δ 自适应标定留作未来工作)；(3) 相对 i.i.d.，burst 的 τ 相对退化率相近
（平静时隙便宜），优势体现在同步效率与绝对 reward。

## RQ4c 随机突发变体（burst-random）：不知道突发何时来也成立

> 配置与 RQ4b 相同，但每个 cycle 的突发起始位置随机（`burst_random=True`，
> 物理世界每集从 rng 抽取 offset；孪生**不知道**突发相位，resample 预测器按
> 非突发采样）。数据：`rq{1,4}_*_burst_random.csv`；图：`fig_burst_random_*.png`、
> `fig_tau_tradeoff_burst_random_*.png`。

k3（5 seeds×10 集，论文主线规模）：

| 机制 | 同步次数 | reward | 完成率 |
|---|---|---|---|
| fixed τ=1 | 101.0 | -6243.9 | 1.00 |
| fixed τ=2 | 51.0 | -8239.2 | 0.88 |
| fixed τ=3 | 34.0 | -9087.6 | 0.87 |
| fixed τ=5 | 21.0 | -10064.6 | 0.84 |
| fixed τ=10 | 11.0 | -11121.4 | 0.77 |
| adaptive load δ=25m | 47.6 | **-8128.1** | 0.88 |
| adaptive load δ=30m | 40.9 | **-8387.2** | 0.89 |
| adaptive load δ=40m | 31.5 | **-8805.6** | 0.88 |
| adaptive load δ=50m | 24.6 | **-9072.9** | 0.86 |
| adaptive per_user δ=10m | 95.1 | -6395.2 | 0.99 |

单 UAV（40 集）：adaptive load δ=40（14.4 次，-289.8）≈ fixed τ=2（16 次，-284.5），
δ=50（11.8 次，-311.7）略胜 fixed τ=3（11 次，-317.0）；per_user δ=10（22.8 次，-219.1）
逼近 τ=1。单 UAV 优势弱于 k3。

**结论（关键）**：
- **优势不是"提前知道突发时刻"换来的**。随机突发下孪生完全不知道突发何时出现，
  k3 的负载感知触发仍然支配固定周期前沿：δ=30（40.9 次同步）在 **reward 与同步次数
  两个维度同时胜过** fixed τ=2（51 次，-8239）；δ=50（24.6 次）拿到 fixed τ=3
  （34 次）同等的 reward，且比 fixed τ=5（21 次）好 9.8%。
- **优势随规模增大而增强**：k3（51 用户）聚合负载信号平滑，突发跃迁与分布内噪声
  分离更干净；单 UAV（12 用户）负载噪声大，自适应只能与最优固定周期打平
  （不再需要先验 τ 仍是优点）。这为"事件触发同步更适合大规模系统"提供了证据。
- per_user 触发在任何 burst 变体下都"过火"（95 次同步逼近 τ=1）——再次验证
  触发指标应反映"控制相关"的负载场变化，而非原始逐用户状态差。

**对创新点 2 的定位**：负载感知事件触发同步（LAETS）= 提出孪生-物理同步架构 +
 控制相关误差度量；在 i.i.d. 下与最优固定周期持平（免先验 τ），在突发（含未知
 相位的随机突发）下以更少同步取得更优/相当性能；与创新点 1 的因果链：
 孪生新鲜度 → 状态精度 → 决策顺序收益。

## 对论文主线的意义

- 数字孪生质量（同步周期/任务建模）是"卸载决策最优性"的上游约束——与 PMEO 决策顺序发现
  构成因果链：孪生新鲜度 → 状态精度 → post-move 精确卸载收益。
- 免训练决策器 + 事件触发同步 = 低开销高鲁棒部署形态（无需训练、无需固定同步周期）。
- 待补：任务到达时间相关场景（突发/稀疏）下自适应 vs 固定的定量收益；k3 完整表。
