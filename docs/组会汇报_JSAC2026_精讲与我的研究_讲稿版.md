### 2.1 研究背景与动机

**论文的逻辑链**（建议按这条链讲，不要平铺）：

1. 6G 要全球覆盖，SAGIN 是核心架构，但**能效是可持续性的命门**
2. 卫星侧走 MEC 化（CubeSat/纳米卫星轻量、便宜、易部署），算力下沉、降低回传压力
3. UAV 提供视距覆盖、可动态重定位，但**航程和能量受限**，必须做轨迹规划
4. 数字孪生作为物理系统的高保真虚拟副本，支撑预测性分析与智能决策
5. 但经典 DRL 在**高维状态动作空间**下收敛慢、需要大量训练回合，在异构 SAGIN 里可扩展性差
6. 量子计算提供并行性与指数级状态空间表示能力，**用量子线路把经典数据编码进量子态**，让智能体用更少的训练回合探索更大的解空间
7. 现实约束：当前是 NISQ 时代，量子硬件受限，所以本文**用仿真模拟量子线路**，而不是跑在真实量子硬件上

**讲稿**：

> 它的动机链是：SAGIN 能效是关键 → UAV 能量受限必须规划轨迹 → 经典 DRL 在高维耦合空间里探索效率不够 → 用量子编码增强特征表示来加速收敛。作者也明确承认这是仿真模拟，不是在真实量子硬件上跑的。

### 2.2 系统模型（§II）：三层架构 + 双电池

**三层结构**：

- **地面层**：M 个接入点（AP），每个 AP 汇聚其注册用户的数据，在 URLLC 约束下传给 UAV
- **空中层**：UAV 搭载 MEC 服务器，配 K 根天线（K = 8），固定高度 H 飞行，从各 AP 采集任务
- **空间层**：1 颗主纳米卫星（MNS）+ 4 颗从纳米卫星（SNS，记 I = {1,2,3,4}）。MNS 负责协调与**负载分配**，SNS 各配单天线与 MEC 能力
- **供能**：地面基站（BS）用无线供能（WPT）给 UAV 的**第二块电池**充电

**关键设计——双电池**：

- 主电池：只负责**飞行能耗**，能量更新为减式（12）
- 副电池：只负责**任务处理与卸载能耗**，由 WPT 充电，受**能量因果约束**（18p）

> 这里可以强调一句：双电池把"飞"和"算"的能量账户分开，这是它建模上比较讲究的地方。

**坐标与几何**：AP 在 (x, y, 0)；UAV 在 (x_u, y_u, H)，H = 100 m；MNS 在轨道高度 R = 300 km；4 颗 SNS 以 MNS 为中心排成正方形。**假设卫星连续覆盖**（因 LEO 密集部署），并假设多普勒已补偿。

### 2.3 信道模型（式 1–5）

论文分三段信道，各用不同模型：

**① AP → UAV（式 1–3）**：概率性 LoS 模型

- 信道向量：g_m,u(t) = √(h_m,u(t)) · g̃_m,u(t) ∈ C^{K×1}，其中 g̃ 是小尺度衰落，E[|g̃|²] = 1
- 大尺度系数（式 2）：h_m,u = (4πf_c·d_m,u / c)^(−α) · 10^(−(κ_los·η_los + κ_nlos·η_nlos)/10)
- LoS 概率（式 3）：κ_los = [1 + μ1·exp(−μ2·(arctan(H/d_hd) − μ1))]^(−1)，κ_nlos = 1 − κ_los
- 直觉：**仰角越高、LoS 概率越大**，遮挡带来的附加路损 η_nlos 就越少

**② UAV → MNS（式 4）**：阴影莱斯（shadowed-Rician）衰落

- g_k(t) = √(h_k(t)) · d_u,ms^(−α/2)，h_k ~ SR(Ω_k, Δ_k, ε_k)
- Ω_k 是直射分量平均功率，Δ_k 是散射多径半平均功率，ε_k 是 Nakagami-m 参数

**③ MNS → SNS（式 5）**：自由空间路损 + 复高斯小尺度

- h_ms,ss(i) = 10^(−κ_ms,ss(i)/10)，κ = 10α·log10(4πf_c·d_ms,ss(i)/c)，g̃ ~ CN(0,1)

**讲稿**：

> 它给三段链路配了三种不同信道模型：AP 到 UAV 用概率 LoS，UAV 到卫星用阴影莱斯，星间用自由空间加复高斯。这个分层建模和它的三段架构是对应的。

### 2.4 通信速率模型（式 6–8）：这里是 URLLC 的关键

**① AP → UAV（式 6）——有限码长公式**：

R^u_m(t) ≈ B · [ log₂(1 + γ^u_m(t)) − √(V^u_m(t)/N) · Q⁻¹(ε^u_m) / ln2 ]

- B：带宽；N：块长度；ε^u_m：解码错误概率
- Q⁻¹(·)：Q 函数反函数
- 信道色散 V^u_m(t) = 1 − [1 + γ^u_m(t)]^(−2)
- 信噪比 γ^u_m = p_m‖g_m,u‖² / σ_u²

**这是 URLLC 与普通香农公式的区别**：香农容量是码长趋于无穷的极限；URLLC 要求短包、低错误率，所以速率要**减去一个由错误概率和块长度决定的后备项**。块越短（N 小）、错误率要求越严（ε 小），这个扣减越大。

**② UAV → MNS（式 7）**：R^ms_u = B·log₂(1 + p_u‖g_u,ms‖²/σ_ms²)（香农公式）

**③ MNS → SNS（式 8）**：R^ss(i)_ms = B·log₂(1 + p_ms,ss(i)|g_ms,ss(i)|²/σ_ss(i)²)

> 讲稿提示：这里可以点一句"**只有第一跳用了有限码长模型，后两跳用香农容量**"——这是个可以讨论的建模选择（后面 Q&A 会用到）。

### 2.5 UAV 移动性与飞行能耗（式 9–12）

**位置更新（式 9–10）**：

x_u(t+1) = x_u(t) + d_x(t) + Δx_u(t)
y_u(t+1) = y_u(t) + d_y(t) + Δy_u(t)

- d_x, d_y 是控制量（轨迹决策变量）
- Δx_u, Δy_u ~ N(0, σ²) 是**风扰动的随机位移**

**速度**：v_u(t) = d_xy(t)/τ_t，其中 d_xy = √(d_x² + d_y²)

**旋转翼功率模型（式 11）**：

P(v) = χ1·(1 + 3v²/w_tip²) + χ2·[ √( √(1 + v⁴/(4w_0⁴)) − v²/(2w_0²) ) ] + ½·τ·ρ·Υ·A·v³

三项的物理含义：
- 第 1 项：**桨叶型面功率**（与 v² 有关）
- 第 2 项：**诱导功率**（悬停时最大、随速度下降）
- 第 3 项：**废阻功率**（与 v³ 成正比，高速时主导）

> 这是无人机通信领域的经典推进功率模型，值得记住：**悬停不省油，但飞太快也费油，存在一个能耗最优速度。**

**主电池更新（式 12）**：E_batt(t+1) = E_batt(t) − E_fly(t)，E_fly(t) = P(v(t))·τ_t

### 2.6 任务接纳、传输与处理（式 13–14）

**任务定义**：J_m = {D_m, Q_m, T^max_m}——数据量、计算复杂度、最大时延

**接纳规则**：

- 二元变量 π_m(t) ∈ {0,1} 表示是否接纳该 AP 的任务
- 仅当 AP 在覆盖范围内（d_hd < d_max = 200 m）才能传
- **每个时隙只接纳一个 AP**，其余等下个时隙
- **每个 AP 在整个任务周期内最多被服务一次**（约束 18i）

**卸载**：δ_m(t) ∈ [0,1] 是卸载到 MNS 的比例，本地处理 (1 − δ_m(t))

**能量（式 13–14）**：

- AP 传输能耗：E^trans_m,u = π_m · p_m · D_m / R^u_m
- **UAV 本地处理能耗（式 13）**：E^proc_m,u = ξ_u · (1 − δ_m) · Q_m · (f^u_m(t) − f̂^u_m(t))²
- UAV 卸载传输能耗：E^trans_u,ms = p_u · δ_m · D_m / R^ms_u
- MNS → SNS 传输能耗（式 14）：E^trans_ms,ss(i) = θ_m,i · p_ms,ss(i) · δ_m · D_m / R^ss(i)_ms
- SNS 处理能耗：E^proc_ss(i) = θ_m,i · ξ_ss(i) · Q_m · δ_m · (f^ss(i))²

**⚠️ 请特别注意 f̂^u_m(t) 这一项**——这是全文数字孪生误差的**唯一载体**，下一节和"抓手"部分都会回到它。

### 2.7 时延模型（式 15）

T^total_m(t) = T^trans_m,u + T^proc_m,u + T^trans_u,ms + max_i { T^trans_ms,ss(i) + T^proc_ss(i) }

其中：

- T^trans_m,u = π_m·D_m/R^u_m（AP → UAV 传输）
- **T^proc_m,u = (1 − δ_m)·Q_m / (f^u_m(t) − f̂^u_m(t))（式 15，UAV 本地处理）**
- T^trans_u,ms = δ_m·D_m/R^ms_u（UAV → MNS）
- T^trans_ms,ss(i) = θ_m,i·δ_m·D_m/R^ss(i)_ms（MNS → SNS）
- T^proc_ss(i) = θ_m,i·δ_m·Q_m/f^ss(i)（SNS 处理）

**关键观察**：最后一项取 **max over i**，因为 MNS 并行分发给 4 颗 SNS，整条链路的时延由**最慢的那颗**决定——这就是为什么要做负载均衡（θ 变量）。

### 2.8 无线供能模型（§II-F，式 16）

- 信道增益：h_bs,u(t) = G_bs · G_u · h₀ · d_bs,u^(−2)
- 收集能量：E^hav_u(t) = η_u · P_bs · h_bs,u(t) · τ_t，η_u ∈ (0,1] 是 RF-DC 转换效率
- 副电池更新：E^hav_stored(t+1) = E^hav_stored(t) + E^hav_u(t) − Σ_m ( E^proc_m,u(t) + E^trans_u,ms(t) )

**能量因果约束（18p）**：Σ_m (E^proc_m,u + E^trans_u,ms) ≤ E^hav_stored(t) + E^hav_u(t)

含义：**这一时隙要用掉的能量，不能超过已有存货加上本时隙收集到的量**——不能透支未来的能量。

### 2.9 问题建模（式 17–18）：全文的骨架

**优化变量集合** Ω = {π, δ, θ, d, f^u}，即：

| 变量 | 含义 | 类型 |
|---|---|---|
| π = {π_m(t)} | 任务接纳决策 | 二元（0/1） |
| δ = {δ_m(t)} | 卸载到 MNS 的比例 | 连续 [0,1] |
| θ = {θ_m,i(t)} | 任务在 4 颗 SNS 间的负载分配 | 连续 [0,1] |
| d = {d_x(t), d_y(t)} | UAV 每时隙位移（轨迹） | 连续 |
| f^u = {f^u_m(t)} | UAV 计算频率分配 | 连续 |

**目标函数（式 17）**：

f(Ω) = Σ_t w1·E^fly_u(t) + Σ_t Σ_m π_m(t)·( w2·E_m(t) + w3·T^total_m(t) )

即：**飞行能耗 + 任务能耗 + 任务时延 的加权和**。权重 (w1, w2, w3) = (5×10⁻⁴, 0.5, 0.5)。

**约束（18b）–（18q）共 16 条**（**（18a）是目标函数本身**，不是约束），建议归类记忆：

| 类别 | 约束 | 含义 |
|---|---|---|
| 变量范围 | (18b)(18c)(18j) | δ∈[0,1]、π 为二元、θ∈[0,1] |
| 时延 | (18d) | 接纳的任务必须在 T^max_m 内完成 |
| 轨迹 | (18e)(18f) | 每时隙位移 ≤ v_max·τ_t；位置在区域边界内 |
| 覆盖 | (18g) | 接纳任务时 AP 必须在覆盖半径 d_max 内 |
| 负载分配 | (18h) | Σ_{i=1}^{4} θ_m,i(t) = 1（分配比例求和为 1） |
| 服务次数 | (18i) | Σ_t π_m(t) ≤ 1（每个 AP 最多服务一次） |
| 速率 | (18k) | 三条链路速率 ≥ R_min |
| 主电池 | (18l)(18o) | 累计飞行能耗 ≤ 电池容量；每时隙电量非负 |
| 算力 | (18m)(18n) | f^u_m − f̂^u_m ≥ 0（有效频率非负）；f^u_m ≤ f^max |
| 副电池 | (18p)(18q) | 能量因果；收获能量存储非负且不超上限 |

**问题性质**：MINLP——**混合整数非线性规划**。难点在于：

- 离散（π）与连续（δ, θ, d, f^u）变量共存
- 能量、时延、移动性三者强非线性耦合
- 高维搜索空间 + 变量强相互依赖

> 讲稿提示：这一段要讲出"**为什么不能直接求最优解**"——离散连续混合、非凸、维度高、还有随机风扰动和时变信道，所以作者转向 DRL。这为"我用枚举求解"埋下对比伏笔。

### 2.10 求解：MDP 建模与奖励设计（式 19）

**动作空间**：a(t) = {π(t), δ(t), θ(t), d_x(t), d_y(t), f^u(t)}

- 注意 π(t) 是**选择本时隙接纳哪个 AP 的索引**（不是对所有 AP 的 0/1 向量）
- 被接纳的任务存入 UAV 队列，在后续时隙处理

**奖励函数（式 19）**：

r(t) = (1/WS)·[ −w1·E^fly_u(t) − Σ_m π_m(t)( w2·E_m(t) + w3·T^total_m(t) ) ] + B(t) − P(t)

- **负号**：最小化代价 ⇔ 最大化累计回报
- **WS**：奖励缩放因子（注意是**除以** WS，不是乘以）
- **B(t)**：奖励项 = B(served) + B(all served)，服务成功给奖励、全部 AP 服务完给大奖励；否则为 0
- **P(t)**：惩罚项，用于强制满足约束 (18b)–(18q)，违反就扣

设计意图：**在"降低成本"和"完成服务"之间做平衡**，同时保证约束满足。

### 2.11 算法：量子编码 + QNN + 两个 QD-DRL

**第一步：量子编码（AELP，角度编码 + 可学习参数）**

流程：

1. 经典观测 s(t) ∈ R^{ds} → 训练一个线性层得到 y(t) = W′s(t) + b，y(t) ∈ R^{2n}
2. 归一化：ỹ(t) = y(t)/‖y(t)‖₂
3. n 个量子比特从基态 |0⟩^⊗n 出发，施加**输入相关的 RY、RZ 旋转**
4. 编码酉算子（式 20）：U_enc(ỹ) = Π_{r=1}^{n} [ (⊗_{j=0}^{n−1} RY(θ^y_{r,j}) RZ(θ^z_{r,j})) · (Π_{j=0}^{n−2} CNOT_{j,j+1}) ]
5. 得到量子态 |s_q(t)⟩ = U_enc(ỹ(t))|0⟩^⊗n

> 直觉解释：**把经典特征"转"成量子比特的旋转角度**，而且旋转角度本身也可训练，所以编码层是能跟着学习过程一起自适应的。

**第二步：变分量子神经网络（QNN，式 21）**

U(Φ, Θ) = Π_{l=1}^{L} [ (⊗_{i=0}^{n−1} RY(Φ^(l)_i) RZ(Θ^(l)_i)) · (Π_{i=0}^{n−2} CZ_{i,i+1}) ]

- 每层：先做单比特旋转 RY/RZ，再用 CZ 门做**近邻纠缠**
- 纠缠的作用：建模状态变量之间的耦合关系（在 SAGIN 里这个耦合很强）
- 设计上保持"硬件友好"和"浅层"——因为深度增加会带来训练困难（barren plateau 问题）

**第三步：测量与解码**

- 在 Pauli-Z 基下测量，得到期望值 ⟨Z_i⟩
- Actor 侧：解码函数把期望值映射成正态分布 N(μ, σ) 的均值 μ（线性层 + tanh），σ = exp(σ_log)
- Critic 侧：解码成标量价值函数 V(s)
- **实测中会重复 N_shot 次取平均**以抑制采样噪声（本文 1024 shots）

**第四步：QD-CE-PPO（Algorithm 1）**

- TD 目标（式 22）：y(t) = r(t) + γ·V(s(t+1))
- 优势函数（式 23）：A(t) = r(t) + γ·V(s(t+1)) − V(s(t))
- Actor 损失（式 24）：**PPO 裁剪目标**，用 ε 限制单次策略更新幅度
- Critic 损失（式 25）：均方误差 E[(V(s(t)) − y(t))²]
- 流程：收集 rollout → 计算 TD/优势 → 做 K 轮 minibatch 更新

**第五步：QD-CE-A2C（Algorithm 2）**

- 结构更简单：每个时隙直接用 critic 估计 V(s(t)) 与 V(s(t+1))，算优势就更新
- Actor 损失（式 31）：E[−log π(a|s)·A(t) − C_e·H(π)]，**多了一个熵正则项**鼓励探索
- Critic 损失（式 32）
- 每个时隙都更新（不需要等 rollout 收集完）

**两种算法的取舍（作者自己的表述）**：

| | QD-CE-PPO | QD-CE-A2C |
|---|---|---|
| 更新机制 | 裁剪限制策略突变 | 简单 actor-critic，逐步更新 |
| 优势 | 稳定性好、鲁棒 | 结构简单、单步复杂度低 |
| 劣势 | 更新复杂度更高 | 对奖励波动更敏感、收敛稳定性差 |
| 适用 | 状态转移高度动态、重稳定性 | 重实现简单、低学习复杂度 |

**复杂度分析**：

- AELP 编码：O(Bn²)
- QNN 演化（L 层）：O(BL(3n−1))
- 测量（N_shot 次）：O(Bn·N_shot)
- 经典解码：O(n(d_c + d_d + 1))
- **单步总复杂度**：O(Bn(L(3n−1) + N_shot + d_c + d_d + 1))
- **总复杂度**：O(E·N_e·T·B·n·(L(3n−1) + N_shot + d_c + d_d + 1))

### 6.2 场景与仿真器

- **仿真器自建**：LoS/NLoS 概率信道、共享计算队列、旋翼飞行能耗、道路网移动模型、移动热点任务生成、突发流量
- **对照基线**：26 个，含 DRL（DQN/TD3/SAC/PPO/GAT-PPO/Transformer-PPO）、MPC（H=3/10/30）、启发式（TEA/Follow-TEA/Greedy）、退化策略（Local-only/UAV-only/LEO-only/Random）
- **统计口径**：单机 40 集（同一 seed 的 episode 配对）、多机 10 seeds × 10 集；配对 t 检验 + Wilcoxon

### 6.3 我的方法一：PMEO（决策顺序）

**问题**：在一个时隙的因果里，UAV **先移动**到新位置 p_t，再用该位置的信道服务本时隙任务。如果卸载决策是在**移动前**的位置 p_{t−1} 上求解的，就等于用"本时隙并不会真正使用的链路速率"做决策。

**做法**：

1. 按任务量做**负载均衡关联**（把用户分配给 K 台 UAV）
2. UAV 在候选移动集里选下一时刻位置
3. **移动到新位置后**，再按实际位置重算信道速率，做精确卸载求解

**卸载求解的具体形式**：对每个用户在候选集 {本地, UAV_1…UAV_K, LEO} × 卸载比例网格 {0, 0.25, 0.5, 0.75, 1.0} 上取 argmin。单机每用户 9 个候选、k3 每用户 17 个候选。因为时隙起始的队列积压固定，代价对用户可加，所以**逐用户搜索就是该时隙的全局最优**（相对该网格）。

> ⚠️ 这一句必须能答上来：老师如果问"你凭什么说是最优"，答案是"**在给定的离散候选集上的最优**，不是连续域全局最优"。

### 6.4 我的方法二：LAETS（负载漂移触发的事件同步）

**数字孪生怎么建**：

- 物理世界 = 仿真器（用户/热点移动、任务按时隙生成）
- 数字孪生 = 每 τ 时隙全量同步一次，间隙内用预测器外推（冻结 / 线性外推 / 线性+噪声 / 重采样）
- **UAV 位置用物理真值**（自定位已知），用户/热点/任务用孪生状态
- 决策器完全复用 PMEO，只改输入

**同步机制**：每 probe_m 时隙抽查 n_probe 个用户，估计"孪生 vs 物理"的偏差（位置误差 + 任务漂移的等效误差），超过阈值 δ 就触发全量同步。

**两种触发指标**：

- `per_user`：逐用户原始状态差（对 i.i.d. 重采样噪声过敏）
- `load`：**聚合负载的相对变化**（只对负载跃迁响应，即部署中真正"控制相关"的量）

4. **LEO 目前是静态高增益回传**：还没有可见窗口，配不上"空天地一体化"的完整含义
5. **突发模型仍是窗口内 i.i.d.**：不是 MMPP 或真实相关到达

## 7. Q&A 预案

**Q1：这篇论文和你的工作到底什么关系？**
> 同一类问题的不同切片。它把 DT 误差当成给定的 4% 常数并扫了敏感性；我把这个误差做成内生决策变量，实测了它的产生机制（同步陈旧）和控制代价。

**Q2：量子部分你懂到什么程度？**
> 我理解到三层：AELP 把经典特征映射成量子比特的旋转角度且编码参数可训练；变分线路用 RY/RZ + CZ 近邻纠缠做特征变换；Pauli-Z 测量后解码成策略分布的均值。更细的量子线路门级实现我没有深挖。我关注的是它的系统建模，不是量子算法本身。

**Q3：它只建模了 CPU 频率偏差，你为什么说不够？**
> 因为我的实测显示，在孪生状态里**位置误差 20% 以内几乎不影响决策质量，而任务/负载状态漂移是性能崩塌的主因**。它把 DT 误差只加载在计算速率这一个变量上，这相当于假设"其它状态都是准确的"——在我的场景里这个假设站不住。

**Q4：你的方法就是 MPC 的 H=1 吧？**
> 机制上确实等价于"结构化候选集 + H=1 的滚动视界"。我的卖点不是算法新颖性，而是三点：免训练、每时隙毫秒级、候选集设计可解释；以及在多机场景相对 MPC-H3 的显著优势（paired p<0.001，10/10 seeds）——代价是能耗高 2.7%，我如实披露。

**Q5：你说"移动后求解最优"，凭什么说最优？**
> 是**在给定离散候选集上的最优**。因为时隙起始的队列积压是固定的，各用户的代价可加，所以逐用户取 argmin 就等于该时隙在该候选集上的全局最优。连续域全局最优我拿不到，这一点我在论文里会写清楚。

**Q6：你的 DRL 基线为什么这么弱？**（最危险）
> 这是我下一步第一优先级。我怀疑两个原因：一是连续轨迹 + 离散卸载的混合动作空间对标准 DQN/TD3/SAC 不友好；二是超参确实没调好。我打算给出完整的超参搜索记录和训练曲线来区分这两种可能；如果确认是动作空间问题，我会换成 MAPPO/MADDPG 重做基线。

**Q7：孪生同步是不是就是换名字的定期同步？**
> 实测差别是：固定周期在 i.i.d. 流量下最优，但在突发流量下被负载漂移触发支配约 10%；而且**在孪生不知道突发相位时这个优势依然成立**。这是事件触发相对定期同步的实质区别。我在论文里会改用 AoI / 事件触发的坐标来写。

**Q8：你的工作能落到这篇论文的框架里吗？**
> 能。它的优化变量是 Ω = {π, δ, θ, d, f^u}。我的工作是往这个集合里加一个变量——**孪生同步策略**，并把 f̂^u_m 从外生常数变成由同步策略决定的量。这是我下一步 P1 要做的联合优化。

**Q9：为什么不做量子？**
> 我评估过：量子部分的收益主要来自表示能力增强，但代价是 1024 shots 的重复采样和 NISQ 硬件约束。更重要的是，我这条线的瓶颈是**状态新鲜度**而不是**策略表示能力**——把孪生做准，比把策略网络做复杂收益更大。我的数据显示同步放宽 10 倍性能就掉 3.3 倍。

**Q10：接下来三个月做什么？**
> P0（1–2 周）：修 DRL 基线、统一能量口径、把定位改成性能-复杂度 Pareto。
> P1（1 个月）：给相位增益一个解析条件、把 LAETS 阈值 δ 做成自适应并给保证、补 LEO 可见窗口。
