## 2. 论文精讲（12–15 分钟）

### 2.1 研究背景与动机（1.5 min）

- 6G 要求全球覆盖，SAGIN 是核心架构；能耗是可持续性的关键约束（"energy-efficient SAGINs are vital for sustainable communications"）
- 单靠地面或单靠卫星都不够：UAV 灵活但算力与电量有限，卫星算力大但距离远、时延高
- 三个痛点：能量受限、时延约束、星座间负载不均
- 数字孪生在这里的作用：为高动态网络提供可预测的虚拟镜像，支撑在线决策

**讲稿提示**：把「为什么需要三层协同」讲成本文的动机，而不是泛泛介绍 SAGIN。

### 2.2 系统模型（3 min）

三层结构，建议画一张图（可参考仓库已有 `digital_twin_uav_leo/results/fig_dt_architecture.png`）：

- **地面层**：接入点 / 用户，产生计算任务
- **空中层**：UAV 搭载 MEC 服务器，靠无线供能（WPT）收集能量；需要规划轨迹、决定卸载
- **空间层**：纳米卫星星座，带 MEC 能力，需要做负载均衡
- **孪生层**：维护物理网络的虚拟副本，为决策提供状态

**要讲清的四组耦合**（本文的核心难点）：

| 决策变量 | 影响 |
|---|---|
| UAV 轨迹 | 改变信道距离 → 改变可达速率与飞行能耗 |
| 任务卸载决策 | 决定任务去本地 / UAV / 卫星 |
| 计算资源分配 | 决定各节点的排队与服务时延 |
| 卫星负载均衡 | 决定星座整体的利用率与拥塞 |

**关键点**：四者互相耦合——轨迹动一个位置，卸载的最优解就变了；卫星平衡改一下，任务该不该上星也变了。这是它必须用联合优化的原因。

### 2.3 问题建模（2 min）

- 形式化为 **MINLP（混合整数非线性规划）**
- 目标：最小化加权系统代价（weighted system cost）
- 约束：能量约束 + 时延约束
- 难点：整数变量（卸载目标）与连续变量（功率、算力、轨迹）耦合，非凸，无法直接求最优

**讲稿提示**：这里要主动说明「为什么不能像小规模问题那样枚举」——变量维度高、连续-离散混合、卫星星座规模大。这句话为我后面「我的方法为什么可以枚举」做铺垫。

### 2.4 方法：量子驱动 DRL（3 min）

- 提出两个算法：**QD-CE-A2C**（量子驱动成本有效优势演员-评论家）与 **QD-CE-PPO**（量子驱动成本有效近端策略优化）
- 量子部分的两个技术点，讲到这个层次即可：
  - **角度编码 + 可学习参数**：把经典状态编码进量子态
  - **变分量子神经网络（VQNN）**：作为策略/价值网络的函数逼近器
- 目的：增强策略探索能力、加速收敛

**⚠️ 讲稿提示（重要）**：量子部分是这篇论文最难、也最容易在组会上被追问的地方。建议**主动划清**：

> 这篇文章的量子部分我理解到「用变分量子电路替代经典策略网络、靠角度编码把状态映射到量子态、从而改善探索」这一层。我关注的重点不是量子本身，而是它的**系统建模方式和它假设掉的东西**。

这样即使老师追问细节，你也有诚实的位置，而且把讨论引回你准备好的方向。

### 2.5 实验与结果（2 min）

- 对比对象：经典 DRL 基线
- 结论三条：
  1. 成本效率更优（QD-DRL 优于经典 DRL）
  2. 在任务周期内能服务到全部接入点
  3. 累计回报更高、收敛更快

**讲稿提示**：报告结果时只说它宣称了什么，不要替它背书。可以说「作者报告的结论是……」。

### 2.6 论文贡献与边界（2 min）

**它的三个贡献**：

1. 提出「UAV-MEC + WPT 供能 + 纳米卫星星座」的能量感知 DT-SAGIN 框架
2. 把轨迹、卸载、算力分配、卫星负载均衡统一为 MINLP
3. 用量子增强 DRL 求解，并报告了相对经典 DRL 的收敛与回报优势

**它的三个空白（我的机会，务必讲出来）**：

1. **数字孪生被当作理想组件**。全篇没有同步模型、没有同步开销、没有陈旧度约束——孪生状态永远准确可用
2. **孪生质量不是决策变量**。四个决策变量里没有「什么时候更新孪生」
3. **没有刻画「陈旧到什么程度会出问题」**。我的实验直接给了这条曲线

**过渡句**（讲完论文立刻接上）：

> 这篇论文建模很完整，但它把最适合我切入的那一环假设掉了。我接下来讲我这一环的实测数据。

## 3. 我的工作现状（3–4 分钟）

### 3.1 我在做什么

- 场景：车辆（V2X）→ UAV → LEO 三层 MEC，2 km 区域，3 UAV / 51 用户 / 3 个移动热点
- 仿真器：自建三层仿真（LoS/NLoS 信道、队列、飞行能耗、道路网、移动热点、突发流量），26 个基线
- 两条主线：
  - **PMEO**：免训练结构化策略——先按需求移动，再按**移动后**位置精确求解卸载
  - **LAETS**：负载漂移触发的事件同步——数字孪生不按固定周期刷新，而是按决策相关的负载漂移触发

### 3.2 已有结果（用数据说话）

**结果一：卸载求值的相位问题（机制发现）**

| 场景 | PMEO（移动后求值） | Current-pos（移动前求值） | 增益 | 统计 |
|---|---|---|---|---|
| hard（40 集） | -81.7 | -84.1 | +2.5 | 37/40 胜，p<0.0001 |
| hard（200 集） | — | — | +2.64 | 189/200 胜，p<1e-23 |
| stress（40 集） | -135.9 | -139.9 | +4.0 | 37/40 胜，p<0.0001 |

**结果二：孪生新鲜度是上位约束**

| 同步周期 τ | 单 UAV hard | k3（3 UAV / 51 用户） |
|---|---|---|
| 1（完美同步） | -80.7 | -3568 |
| 5 | -209.9 | -6670 |
| 10 | -269.9 | -7565 |

同步放宽 10 倍，性能掉 3.3 倍；且 τ=10 时 PMEO 与 MPC、current-pos 三种决策器趋同——**孪生误差把决策顺序的收益淹没了一个数量级**。

**结果三：孪生里哪部分陈旧最致命**

- 位置线性外推 vs 冻结：-178.5 vs -179.1（几乎无差）
- 位置噪声 20% 以内：无影响
- 任务盲目重采样反而更差（-186.5）
- **结论：任务/负载动态建模远比位置预测重要**

**结果四：事件触发同步在突发流量下形成硬优势**

- i.i.d. 流量下：自适应只能追平最优固定周期（免先验 τ）
- 突发流量下：k3 δ=40（32.3 次同步）比 fixed τ=3（34 次）好 9.7%；δ=50（26.1 次）比 fixed τ=5（21 次）好 10.6%
- 随机突发（孪生不知道突发相位）：δ=30（40.9 次）在 reward 与同步次数两个维度**同时胜过** fixed τ=2（51 次）

### 3.3 我的空白 vs 这篇论文

| 维度 | 本文（JSAC 2026） | 我的工作 |
|---|---|---|
| 数字孪生 | 理想、无成本、无陈旧 | 显式建模同步周期与陈旧代价 |
| 孪生同步 | 不是决策变量 | 事件触发，作为决策的一部分 |
| 状态重要性 | 未区分 | 已量化：任务/负载 >> 位置 |
| 场景 | 纳米卫星星座，连续覆盖 | 车辆-UAV-LEO，含突发流量 |
| 求解 | 量子 DRL | 免训练精确求解 + 事件触发 |

## 4. 我从这篇论文学到的三个思路（3 分钟）

### 思路一：把「加权代价」的口径统一写进目标函数

- 本文用 **weighted system cost**，把能量和时延显式加权，读者一眼能看懂在优化什么
- 我的问题：`energy_weight=0.001`，等于奖励几乎不惩罚能量，但表格又报告能耗——**口径自相矛盾**，这是审稿人必抓的点
- **行动**：要么把 energy_weight 提到有意义量级（0.05–0.5）重跑，要么从贡献里删掉「能效」表述

### 思路二：决策变量的层次感

- 本文四个变量（轨迹 / 卸载 / 算力 / 负载均衡）覆盖了「怎么动 → 送到哪 → 谁来算 → 星座怎么分」
- 我的现状只有「怎么动 + 送到哪」，缺「算力怎么分」
- **行动**：把算力分配加进来，变量层次立刻和顶刊对齐；同时我的 balanced association 本质上就是 UAV 侧的负载均衡，可以用本文的卫星负载均衡做类比论证

### 思路三：对照实验的组织方式

- 本文用经典 DRL 做基线，且基线是**有效**的（不是随便跑的）
- 我的问题：单机 hard 场景 TD3 `-349.2` 比 Random `-340.3` 还差；k3 里 M-DQN `-8659` 对 Random `-9053` 基本打平——**训练的 DRL 打不过随机策略**
- **行动**：这是 P0 第一优先级。要么补超参搜索证据，要么论证「连续轨迹 + 离散卸载的混合动作空间对标准 DQN/TD3 不友好」并引文献，要么换 MAPPO/MADDPG

### （可选补充）如果老师问「有没有教你怎么做理论」

可以提两篇我另外在读的文献：

- **JSAC 2025, "Simple Bounds on Fidelity-Timeliness Tradeoff"**, DOI `10.1109/jsac.2025.3623193`：教的是怎么把一个「权衡曲线」升级成「上下界 + 渐近分析」，正好对应我要补的相位增益解析条件
- **TIT 2026, "From Freshness to Effectiveness: Goal-Oriented Sampling for Remote Decision Making"**, DOI `10.1109/tit.2026.3663678`：核心论点是「新鲜度 ≠ 决策有效性，陈旧的某些数据可能比新鲜数据更有价值」，这与我「任务状态比位置更重要」的实测发现完全一致，可以作为我 LAETS 的理论坐标

## 6. 预期被问到的问题与回答

**Q1：这篇和你的工作到底什么关系？**
> 同一类问题的不同切片。它把 DT 当成理想组件来优化四个决策变量；我的工作是把它假设掉的那一环——孪生同步——量化出来并做成决策变量。它的建模方式我借鉴，它的空白我填。

**Q2：量子部分你懂吗？**
> 我理解到「角度编码 + 变分量子电路替代经典策略网络以改善探索」这一层，更深的量子线路细节我没有深挖。我关注的是它的系统建模，不是量子算法本身。

**Q3：你为什么不做卫星星座？**
> 我的场景是车辆-UAV-LEO，LEO 目前建模为高增益回传，没有做可见窗口。这是我 P1 的第 6 项，我打算复用灾后那条线里已有的简化星历和可见窗剪枝。

**Q4：你的 DRL 基线为什么这么弱？**（最危险的问题，必须先准备）
> 这是我目前最优先要解决的问题。我怀疑是连续轨迹 + 离散卸载的混合动作空间对标准 DQN/TD3/SAC 不友好，也可能是超参没调好。我下一步会给出完整的超参搜索记录和训练曲线来区分这两种可能；如果确实是动作空间问题，我会换成 MAPPO/MADDPG 重做基线。

**Q5：你的方法就是 MPC 的 H=1 吧？**
> 机制上确实等价于「结构化候选集 + H=1 的滚动视界」。我的卖点不是算法新颖性，而是三点：免训练、每时隙毫秒级、可解释的候选集设计，以及在多机场景下相对 MPC-H3 的显著优势（paired p<0.001，10/10 seeds）——代价是能耗高 2.7%，如实披露。

**Q6：孪生同步是不是就是换个名字的定期同步？**
> 我在论文里会主动改用 AoI / 事件触发的坐标来写。实测差别是：固定周期在 i.i.d. 下最优，但在突发流量下被负载漂移触发支配 10% 左右；而突发相位未知时这个优势依然成立——这是「事件触发」相对「定期同步」的实质区别。
