# 0. 先用 1 分钟抓住主线

车算力不够 → 任务可以：

1. 本地算
2. 甩给附近无人机 UAV
3. 经 UAV 传到低轨卫星 LEO

UAV 还会飞。飞到哪，信道好坏就变；飞得猛还费电。

每个时隙（约 1 秒）要决定两件事：

- UAV **往哪飞**（轨迹）
- 任务 **卸到哪、卸多少**（卸载）

我们的方法叫 **PMEO**：

> 用简单规则定「朝哪飞」→ 飞一小步 → 在**新位置**上枚举选最好的卸载。  
> **不训练神经网络。** 创新重点是「必须用飞完后的位置算卸载」，不是网络多深。

多机再做成 **PMEO-M-Eco**；若决策看数字孪生，还要用 **LAETS** 决定何时同步状态（姐妹篇再细讲）。

# 2. 任务怎么来、时延能耗怎么算（建模核心）

## 2.1 任务到达

- 平静区：产生任务概率低（约 0.05）
- 热点附近：概率很高（约 1.0）
- 不是「全世界任务挤成一点」：热点外仍有稀疏任务

## 2.2 三条卸载路

| 路径 | 含义 | 直觉 |
|---|---|---|
| 本地 | 车上自己算 | 不占无线，但车算力弱 |
| UAV | 传到附近无人机算 | 飞近了信道更好 |
| 经 UAV→LEO | 无人机当中继再上卫星 | 算力强，但多一段回传 |

任务可**部分卸载**：本地留一部分、边缘算一部分。实验里比例取离散点：

$$\{0,\ 0.25,\ 0.5,\ 0.75,\ 1\}$$

单机时：3 个目标 × 5 个比例 ≈ **15 个候选**，可以穷举。

## 2.3 时延（人话 + 公式骨架）

端到端时延大致是：

$$\mathrm{时延} \approx \mathrm{传输} + \mathrm{计算} + \mathrm{排队}$$

- 传输：跟距离、LoS/NLoS、带宽、回传有关 → **UAV 位置一变，传输就变**
- 计算：跟算力（车 / UAV / LEO）和任务 cycles 有关
- 排队：多人抢同一 UAV/LEO 队列会互相挤

超时 → 记丢弃，并在代价里重罚。

## 2.4 能耗

两块：

1. 算任务的能耗
2. UAV **飞行能耗**（飞得越快往往越费电；实验用与速度三次方相关的阻力项）

主实验能量权重较小（$w_e=0.001$）：更在乎时延/成功率；能量权重大了，单机上 MPC 的节能优势会露出来（要诚实讲）。

## 2.5 每个时隙优化什么

决策：

1. 各 UAV 位移（不能超过最大速度 $v_{\max}$）
2. 各有任务用户：卸载目标 × 卸载比例

目标（回合累计期望代价尽量小）：

$$\min\ \mathbb{E}\Big[\sum_t \big(L_t + w_e E_t + \lambda D_t\big)\Big]$$

- $L_t$：时延相关代价
- $E_t$：能耗
- $D_t$：丢弃汇总
- $\lambda$：丢弃惩罚（主实验约 4）

实验打印的 **reward ≈ −（上面那坨代价）**，所以 reward 越大越好。

单用户卸载时，PMEO 在网格上比的是：

$$c_u = \mathrm{latency}_u + w_e\cdot\mathrm{energy}_u + \lambda\cdot\mathrm{dropped}_u$$

同一时隙用户代价可加 → 逐用户取最小 ≈ 该时隙在「给定轨迹 + 给定网格」下的最优。

# 3. PMEO 到底怎么做（每时隙都要重算！）

![PMEO 每时隙两步（中文）](../experiments/uav_leo_v2x_paper_final/figures/fig_ch3_pmeo_pipeline_cn.png)

## 3.1 关键问答：一步飞不到目标，那每个时隙都要算吗？

**要。每个时隙都重新算一遍。**

原因很简单：

- 车/任务在变 → **任务质心**会变
- 热点在漂 → **预测热点**会变
- UAV 自己也已经飞到新地方了

所以不是「算一次目标，然后一路冲过去」。而是：

> 每个 1 秒时隙：看一眼现在的质心和热点 → 定一个新的混合目标 → 朝它飞**不超过 $v_{\max}$ 的一小步** → 在新位置枚举卸载 → 下一秒再来。

一步飞不到目标完全正常：像追移动的足球，每秒修正方向。

## 3.2 步骤 A：启发式定轨迹（怎么飞）

**任务质心 $c_t$：** 有任务用户位置的加权平均（活多的地方）。

**预测热点 $h_{t+1}$：** 不是神经网络，是匀速外推：

$$h_{t+1} = h_t + v^{\mathrm{hot}}_t \cdot \Delta t$$

（$\Delta t$ 就是一个时隙时长。）

**混合目标 + 速度裁剪：**

$$p_t = p_{t-1} + \mathrm{clip}\big(0.5\,c_t + 0.5\,h_{t+1} - p_{t-1},\ v_{\max}\big)$$

人话：

1. 目标 = 一半看现在任务在哪，一半看热点下一拍会漂到哪
2. 朝目标飞，但一步位移被 $v_{\max}$ 卡住
3. **这是写死的规则，不是 GNN，也不是图算法**

> 「启发式」= 用领域经验写的简单规则。  
> 图神经网络（GAT-PPO 等）是**别人的对照基线**，不是 PMEO 零件。

## 3.3 步骤 B：移动后精确卸载（怎么卸）

UAV **先按步骤 A 飞到 $p_t$**，再用 **$p_t$ 上的信道**，对每个用户枚举约 15 格，选 $c_u$ 最小的。

复杂度大约 $O(U\cdot 15)$，**零训练**。

## 3.4 为什么强调「移动后」

同一条飞法，如果还在**旧位置 $p_{t-1}$** 上算卸载（Current-pos exact），等于用「本时隙根本不会用的信道」做决策 → 系统性变差。

配对实验（修复版）：hard 约 +2.5、stress 约 +4.0（reward），p 极小。

无热点、任务均匀时，这个优势会缩小 → 说明贡献和「热点带来的较大移动」绑定。

**命题 1（不劣性，答辩可念）：** 真实执行在 $p_t$ 上时，用 $p_t$ 求的最优卸载，代价不会差于用 $p_{t-1}$ 求的。

$$\mathrm{cost}(p_t, O_{\mathrm{post}}) \le \mathrm{cost}(p_t, O_{\mathrm{pre}})$$

# 4. 多机一句话（细节姐妹篇再展开）

$K>1$ 时：

- 用户关联到各 UAV（尽量摊匀，且用移动后位置）
- **PMEO-M-Eco**：在「原地 / 专家飞 / 质心 / …」等候选飞法里，短前瞻挑更划算的（兼顾费电与卸载）

多机 Eco 才是相对 MPC **常能赢**的主战场。

# 6. 读完本篇你应能口头说的 6 句

1. 三条路：本地 / UAV / 经 UAV 上 LEO。
2. 每个时隙都重算：质心 + 预测热点 → 混合目标 → vmax 限一步。
3. 预测热点 = 位置 + 速度 × Δt，不是神经网络。
4. 飞完后在新位置枚举约 15 格卸载。
5. 免训练 = 轨迹规则 + 卸载枚举，不训大模型参数。
6. 创新强调顺序：同一轨迹，post-move 优于 current-pos。
