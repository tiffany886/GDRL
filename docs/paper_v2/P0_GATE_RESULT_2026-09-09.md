## 4. 闸门判定（按预案，不修改声明）

- **红线 A 触发（aligned）**：B7 在成功率与有效时延上均不低于 Ours（成功率甚至更高，
  不显著），能耗显著更低（+3.2 kJ，p=0.006）。即：**若热点位置已知，静止停热点在三个维度
  上都占优**——"巡逻优于悬停"的声明不成立，不能再作为头条。
- **红线 B 触发（interior）**：热点移到小区内部后，Ours 与 B3/B7 的成功率差距消失
  （+0.015 / −0.007，均 n.s.）。**巡逻优势只在"热点位于小区边缘/条带内"时存在**，且相对
  对象是"不知道热点在哪的均匀悬停"（aligned/corners 下 Ours−B3 显著）。
- **可保留的最小声明**：在无热点先验的假设下，条带巡逻是零信息默认策略，能显著优于
  均匀固定站位（aligned +0.095 p=0.001；corners +0.064 p=0.002），并与"知道热点位置"的
  B7 在成功率上无显著差异（差距 ≤0.03，n.s.）；代价是多耗 3–5 kJ 飞行能耗。
