## 主动修正（评审未提但自查发现）

- **v_max 非单调性的旧解释是错的。** 原稿称「由实际移动量驱动」，但实测平均位移随 `v_max` **单调上升**
  （5.97 → 24.91 m/时隙）。正确机制：**决策单元改变频率单调上升**（0.52% → 1.69%），
  而**单次改变的代价落差下降**（20.7 → 5.2），两者相乘使总增益在中等机动处最大。已据实改写并给出表格。
