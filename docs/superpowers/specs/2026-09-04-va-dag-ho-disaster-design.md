## 0. 一句话与锁定开关

**一句话：** 灾后地面回传失效时，多 UAV 作空中边缘、LEO 仅在可见窗内可用；终端产生依赖任务（DAG）。上层 MAPPO 学 UAV 水平轨迹，下层嵌入可见窗感知的 DAG 列表调度；能量有限但不建充电站；主实验不设地面应急站 GS。

| 开关 | 锁定值 |
|------|--------|
| 相对 PMEO/LAETS | 独立题目；主创新不得写成「先飞后卸」或「事件触发孪生同步」 |
| 开发周期 | **5 周**（含画图、复现文档） |
| B7 GDRL | **可选**；主验收不卡 |
| GS 地面应急站 | **主实验去掉**；相关工作/展望写「可扩展地面残站点」；导师强要求空天地含地面时再加弱 GS |
| 能量 | 方案 A：SoC + 耗电 + 低电惩罚，**无充电站** |
| 关联 | **规则**（速率贪心 + 负载上限）；RL **只学飞** |

## 1. 创新点（论文贡献表述）

### 1.1 主贡献

1. **可见窗感知的依赖任务分层决策框架（VA-DAG-HO）**  
   上层多智能体 RL（MAPPO）决策 UAV 轨迹；下层在当前可见窗、信道、队列下对 DAG 做拓扑序约束的嵌入式启发式调度（optimization-embedding）。

2. **可见窗–依赖耦合的可行性与代价模型**  
   卸 LEO 必须窗内可行；跨窗未完成则失败/大惩罚（规则唯一）；证明「常在线 LEO」假设会系统性高估卫星路径。

3. **（弱写、可选）短视界预测辅助**  
   仅作需求/剩余可见时间特征进状态；**不做** LAETS 式同步策略。

### 1.2 优化嵌入含义（给实现与答辩）

RL **不**直接输出每个 DAG 子任务的卸载；每时隙：

`状态 → RL 轨迹动作 → 移动 → 规则关联 →【嵌入 ScheduleDAG】→ 奖励`

轨迹好坏由嵌入调度后的时延/能耗/失败来评价。

### 1.3 禁止写成创新点

- 「用了 MAPPO/SAC」  
- 「场景是灾后」 alone  
- 「联合优化轨迹与卸载」 alone（近五年同款过多）  
- 决策顺序（PMEO）、事件触发孪生同步（LAETS）

## 2. 场景与系统边界

### 2.1 故事

震后/洪后基站与回传失效。救援车、便携终端、临时摄像头产生有依赖的计算应用；多 UAV 接入+边缘计算；LEO 在可见窗内提供高算力回传。

### 2.2 主表实体规模

| 实体 | 主表 | 说明 |
|------|------|------|
| 区域 | \(2\times 2\,\mathrm{km}\) | 灾后走廊 |
| 终端 \(N\) | 30 | 半静态/慢移 |
| UAV \(K\) | 3 | 高度固定 \(H\)（如 100 m） |
| LEO \(L\) | 2 | **交错可见窗**，避免「永远有星」 |
| GS | **无（主实验）** | 展望可扩展 |
| \(\Delta t\) | 1 s | |
| \(T\) | 50 | 时隙/回合 |

附录扫描：\(N\in\{20,30,40\}\)，\(K\in\{2,3\}\)，突发强度 ×1 / ×1.5。

### 2.3 不做的范围

- 完整轨道动力学（用简化星历可见区间即可）  
- 物理层波形  
- UAV 充电站后勤  
- 城市车联网热点道路故事（属 PMEO）

## 3. 任务到达与能量

### 3.1 任务产生

- **单位：** 应用实例 = 一张 DAG（非无结构比特包）。  
- **模板：** 2–3 种（轻/重），节点 4–5，深度 3–4。示例边：`采集→检测→融合→决策`。  
- **到达：** 非齐次泊松；平时 \(\lambda_{\mathrm{low}}\)，中段救援波 \(t\in[15,35]\) 用 \(\lambda_{\mathrm{high}}\)。  
- **绑定：** 应用挂到某一终端 \(n\)；输入数据在 \(n\)。  
- **并发上限：** 每终端未完成应用 ≤ 1–2，防队列爆炸。

### 3.2 能量

- 状态含 \(SoC_{k,t}\)；每步扣飞行 + 通信 + 计算。  
- 低电：限速 / 禁过大机动 / 奖励大惩罚。  
- **不建模充电/换电。**

---

## 4. 信道、可见窗、时延

### 4.1 信道

- 终端–UAV：LoS/NLoS 混合 + 香农速率（可复用现有 `los_nlos` 思路）。  
- UAV–LEO：窗内 \(\min(r_{k,\ell}, C_\ell)\)；**窗外 \(C_\ell=0\)（硬约束）**。

### 4.2 星历

每颗 LEO 给出可见区间列表 \([t^{\mathrm{in}}, t^{\mathrm{out}}]\)；状态中提供剩余可见时间 \(\tau_\ell\)。

### 4.3 DAG 时延（概念）

子任务完成时间受：前驱完成、跨节点传输、排队、计算约束。  
**跨窗规则（唯一）：** 选 LEO 且估计传输+计算超过 \(\tau_\ell\) → **禁止该放置**；若仍超时/无法完成 → 应用失败计入 \(F\)。

---

## 5. 问题形式化

决策：上层轨迹 \(\mathbf{a}_{k,t}\)；下层放置与调度（嵌入）。  

\[
\min \mathbb{E}\Big[\sum_{t=1}^{T}(\alpha_1 L_t + \alpha_2 E_t + \alpha_3 F_t)\Big]
\]

- \(L_t\)：时延相关项  
- \(E_t\)：UAV 能耗  
- \(F_t\)：失败应用数 / 严重违约  

奖励：\(r_t=-(\alpha_1 L_t+\alpha_2 E_t+\alpha_3 F_t)-\) 边界/碰撞软惩罚。  
主表权重固定一组；附录敏感性。

---

## 6. 轨迹（上层）

- 每 UAV 一 agent；MAPPO，CTDE。  
- 动作：水平速度 \((v_x,v_y)\) 或离散方位+速率档；\(\|\mathbf{v}\|\le v_{\max}\)；高度固定。  
- \(\mathbf{p}_{k,t+1}=\mathrm{Proj}_{\mathcal{A}}(\mathbf{p}_{k,t}+\mathbf{a}_{k,t}\Delta t)\)。  
- 观测：自身位置与 SoC、责任区积压摘要、邻机相对位置、各 LEO 的 \(\tau_\ell\)、近期失败统计。  
- **关联不由 RL 输出：** 按 \(r_{n,k}\) 排序 + 每机负载上限。

### 时隙因果顺序（实现必须统一）

```
观测 → RL 轨迹 → 移动并扣飞行电 → 规则关联
    → ScheduleDAG（新位置 + 当前可见窗）
    → 结算 L/E/F → 奖励 →（周期性）MAPPO 更新
```

「先飞后调度」仅为仿真因果，**不得**当作相对 PMEO 的创新点。

---

## 7. 下层嵌入：ScheduleDAG

多项式启发式，论文称「嵌入式启发式近似求解器」，不宣称逐步全局最优。

1. 构造就绪集 \(R\)（前驱完成且数据可达）。  
2. 按紧急度排序（截止期 > 重节点 > 普通）。  
3. 对每个 \(v\in R\)，枚举候选：关联 UAV、窗内 LEO：  
   - 估 \(\hat{T}=T^{\mathrm{tx}}+T^{\mathrm{wait}}+T^{\mathrm{cmp}}\)  
   - **可见窗剪枝：** LEO 且耗时 \(>\tau_\ell\) → 禁止  
   - 选估代价最小的可行放置；均不可行则等待或累计失败风险  
4. 同节点内按紧急度/FCFS 占用算力；更新队列与 SoC。  
5. 汇点完成 → 成功；超应用截止期 → 失败。

单元测试硬要求：

- 前驱未完成不得开工  
- 窗外 \(C=0\)；跨窗 LEO 放置被拒绝  
- 依赖违反计数在合法调度下为 0

## 8. 对比算法与消融

### 8.1 主验收必须实现（B1–B6）

| ID | 方法 | 轨迹 | 卸载 | 证明点 |
|----|------|------|------|--------|
| B1 | Random / Sweep + 同下层 | 固定 | 同 ScheduleDAG | 不会飞不够 |
| B2 | Chase-Backlog + 同下层 | 追积压质心 | 同 | vs 短视追热点 |
| B3 | Hover + 同下层 | 悬停 | 同 | 机动价值 |
| B4 | 扁平 MAPPO/IPPO | 学 | 学（无嵌入） | 嵌入必要 |
| B5 | 扁平 MADDPG 或 MATD3 | 学 | 学 | off-policy |
| B6 | DAG 感知但无可见窗剪枝（常在线/弱窗） | 同或简化 | 无 VW-prune | 剪枝贡献 |

### 8.2 可选

| ID | 说明 |
|----|------|
| **B7 GDRL** | 有余力再接；**主验收不卡** |
| B8 短视界 MPC 轨迹 + 同下层 | 上界/免训练参考 |

指标：应用成功率、平均完成时延、UAV 总能耗、无效 LEO 尝试次数、学习法墙钟时间。  
**≥5 seeds**，均值±标准差。禁用「仅 2018 前 DQN 冒充 SOTA」。

### 8.3 消融

- w/o VW-prune  
- w/o DAG-order（当独立任务）  
- w/o embed（=B4）  
- w/o energy-in-state
